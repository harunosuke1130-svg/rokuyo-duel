図鑑

六耀の地の仲間たち。タップすると技・固有スキル・リーダースキルをすべて見られます。まだ仲間にしていないキャラはガチャで呼べます。

所持：0 / 0

チーム・キャラ

持っているキャラから異なる6体を選んで保存します。各キャラの「技の入れ替え・並べ替え」で出目1〜6への割り当てを変えられます。レベルが上がると最大HPと通常技の攻撃が上がります。

選択中：0 / 6

対戦（CPU）

CPUのチームと6対6で戦います。ランク戦は上から順に、勝つと次の相手が出てきます。勝つとチーム6体が経験値を得て、初勝利では石をもらえます。

ダンジョン

6人のチームで、1階の雑魚・2階の中ボス・3階の大ボスを1体ずつ順番に倒します。HPと戦闘不能は次の階に引き継ぎ。大ボスを倒すと踏破で、石がもらえます。勝った階では経験値も入ります。

ガチャ

石を使ってキャラクターを呼びます。全キャラ同じ確率です。持っていないキャラは仲間になり、持っているキャラが出たら経験値に変わります。石はダンジョン・ログインボーナス・対人戦で手に入ります（お金は使いません）。
